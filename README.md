# AI Roleplay Simulation Website

Practice real-world scenarios for sales, customer support, and contact center professionals using AI-powered roleplay simulations.

## How to Deploy
1. Upload all files to your public GitHub repository.
2. Go to **Settings > Pages**.
3. Set branch to `main` and folder to `/ (root)`, then Save.
4. Wait a few minutes. Your site will be live at `https://YOUR-USERNAME.github.io/ai-roleplay-simulations/`.

## Features
- Three pre-built simulation scenarios
- Custom scenario builder
- Responsive chat interface
- Local storage for API keys (never leaves your device)

## Configuration
- API keys are only stored in your own browser.
- Project works with OpenAI GPT, Claude, Gemini APIs (integration customization needed in `app.js`).
